Leakage explanation (4 lines)
1. Scaling before splitting calculates statistics using both training and test rows.
2. This lets information from the held-out test data influence preprocessing.
3. Correct practice is to fit the scaler on training data only and transform validation/test data.
4. A Pipeline applies this rule within each cross-validation fold and prevents leakage.
